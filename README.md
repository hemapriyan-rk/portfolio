# Portfolio

Personal portfolio for Hemapriyan R K. Next.js (App Router), statically exported (`output: "export"`) and deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
```

Content lives in `src/data/content.ts`, the page is `src/app/page.tsx`, and the theme toggle is `src/components/ThemeToggle.tsx`.
